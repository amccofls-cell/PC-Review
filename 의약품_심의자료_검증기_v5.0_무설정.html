GitHub Pages 1회 배포 (영구 호스팅)

  1. github.com/new 접속 → 로그인
    • Repository name: drug-verify (아무 이름 OK)
    • ☑ Add a README file 체크
    • → Create repository 클릭
  2. 리포 페이지에서 Add file → Upload files 클릭
    → 방금 받은 의약품_심의자료_검증기_v5.0_무설정.html 끌어다 놓기 → 하단 Commit changes 녹색 버튼 클릭
  3. 리포 상단 Settings 탭 → 왼쪽 Pages 메뉴
    • Source: Deploy from a branch
    • Branch: main, Folder: / (root) → Save
  4. 1분 기다리면 https://<내계정>.github.io/drug-verify/의약품_심의자료_검증기_v5.0_무설정.html 가 열림 → 북마크

이후엔 그 주소만 열어 쓰면 됩니다. 매번 다운로드할 필요 없음.

키 발급 (1회만)

  1. data.go.kr 가입 → 마이페이지 → 인증키 발급
  2. 다음 두 가지 모두 발급 (1개씩):
    • 「의약품 허가정보 서비스」
    • 「건강보험심사평가원 약가기준정보조회서비스」
  3. HTML 상단 [🔑 키 등록] 클릭 → 두 키를 mfds키,hira키 형태로 붙여넣기 → 저장
  4. 키는 본인 브라우저 localStorage에만 저장. 외부 전송 ❌
  5. 공유 PC 사용 시 [🔄 키 회전] 으로 새 키로 교체
